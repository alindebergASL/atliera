# C3 completion v3 — UI release candidate

This UI-only slice improves the existing private account-to-meeting workspace independently of the separately isolated generation-contract repair. It does not enable fresh generation, perform deployment, introduce persistence or provider routes, or grant effect permission. The effect declaration describes this repository change, not the separately authorized checked private-preview operation.

## What changes for the user

- Overview and Research details explain retained research context first. Evidence remains the exact retained passage, with source inspection and a return to the prior detail or revision state. Opening either view does not request generation.
- Saved briefs use concise editable titles, useful content previews and existing truthful saved metadata. Notes and titles still use the existing explicit save and versioned reopen contracts.
- Mobile uses compact title/metadata/actions and readable 16px document body text, bringing Situation closer to the first screen without removing meeting setup.
- Revision leads with the instruction, proposed text, original section and explicit Apply. Historical replay has a concise label and a fixed recorded instruction; selecting that instruction preserves the chosen section. Applying refreshes the original preview from the selected section of the applied draft.
- Repeated detail affordances, oversized source headings and inconsistent inspector controls are reduced. Native Tab stays in the open modal and Close restores the launching control.

No new research was acquired.
