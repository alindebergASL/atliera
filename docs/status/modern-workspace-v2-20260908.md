## What is connected

- Preparation carries account context into audience, outcome, date and duration. Provider-disabled and curated-only modes explain their limits before submission and offer the worksheet rather than a misleading generation action.
- Brief revision compares original and proposed work. Only explicit **Apply** changes the working brief; generating, cancelling or rejecting a proposal does not silently replace it. Historical replay requires the exact retained request and correction.
- **Save** acknowledges a private local immutable version only after synchronized persistence and validated readback. Saved work can reopen in a new browser session after process restart with the configured operator identity. Notes remain annotations rather than generated or ratified account facts.
- Same-session stale tabs, stale durable versions, in-flight changes and recovered browser notes cannot claim Saved without the corresponding current acknowledgement. Local recovery and durable persistence are visibly different states.

## Local operation and limits

Build using `npm run build`. Existing CLI modes remain separate:

```sh
# Default closed, retained account context; no model command selected.
C3_PORT=4317 node dist/c3/atliera-c3.js serve acc_university_of_utah

# Exact historical replay, explicitly labeled and never a live fallback.
C3_PORT=4317 \
C3_WORK_STORE_ROOT=<private-absolute-directory> \
C3_OPERATOR_PRINCIPAL=<stable-operator-id> \
node dist/c3/atliera-c3.js serve-recorded <private-recording-directory> acc_university_of_utah
```

Replace placeholders before execution. Keep the work store outside served assets. The principal comes from trusted operator configuration, not browser input; this is not multi-user authentication. Keep loopback binding and exact Host/Origin protections. An existing authorized same-port SSH tunnel can provide private access; an agent-local URL alone is not owner-accessible proof. No new public exposure or subscription is authorized here.

OpenRouter is not a product commitment. Gateway routes and direct provider APIs such as Anthropic API and OpenAI API remain first-class replaceable options behind the provider boundary, without product-logic rewrites. This status selects no new route, enables no tools/search/plugins, restores no consumed historical call authority, and makes no broad model-quality or launch-readiness claim.
