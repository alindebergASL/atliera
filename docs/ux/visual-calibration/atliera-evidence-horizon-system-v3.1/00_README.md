# Atliera Evidence Horizon System v3.1

Status: **owner-approved visual calibration amendment** — approved by Andrew Lindeberg on August 18, 2026. This packet is not implementation authority by itself.

This packet turns the calm-product pivot into a broader, production-oriented product language. It shows how Atliera can surface the most useful account intelligence, preserve trust without warning walls, and progressively support evidence review, strategy, meeting preparation, briefing approval, conflict handling, mobile use, and recurring monitoring.

Version 3.1 explicitly preserves the four predecessor visual-generation v2 concepts as Atliera's expressive and originality floor. v2 contributes premium composition, change-horizon identity, question-led exploration, and visual “wow”; v3 contributes usability, trust, states, responsiveness, and implementation precision. `Workshop` remains a future calm account-local mode rather than being removed or confused with the M5b Package Inspector.

This version supersedes v3 for any C1 handoff that has not started. v3 remains an immutable predecessor record. See `05_CHANGELOG_AND_LINEAGE.md`.

## Public-source calibration scenario

The University of Utah scenario is grounded in an official university article dated June 19, 2026. It reports that the university is redirecting $4.94 million into artificial intelligence within a three-year reinvestment process.

Primary amount source:

- [University of Utah continues reinvestment in AI, behavioral health, nursing](https://attheu.utah.edu/business/university-of-utah-continues-reinvestment-in-ai-behavioral-health-nursing/)

Related context sources, which describe separate initiatives and must not be blended into the $4.94M claim:

- [U building AI ecosystem with tech powerhouses](https://attheu.utah.edu/artificial-intelligence/u-building-ai-ecosystem-with-tech-powerhouses/)
- [U to build out Utah Health AI Vault with state support](https://attheu.utah.edu/science-technology/u-to-build-out-utah-health-ai-vault-uhaiv-with-state-support/)

The visuals deliberately do **not** claim that $4.94M is remaining cash, available seller budget, an opportunity value, procurement, vendor intent, or buying intent. Visual 06 and the conflict example in Visual 08 use a clearly fictionalized later source solely to calibrate conflict handling.
