## Three bounded outcomes

1. **Truthful provenance.** Historical replay uses a neutral origin badge rather than a success treatment. Unknown origin remains unknown. The latest review disclosure uses the stored action, timestamp, configured-operator actor and unchanged reason; it does not infer human, agent or trial authorship from prose. Original history remains inspectable.
2. **Scannable information and evidence.** Cards retain local uncertainty/status, entity/time scope and publication/current-through dates, including unknowns. Repeated explanations move into **Why these labels**. Literal local search indexes statements, entity/scope and source material, not boilerplate trust labels or trial-history prose. Evidence choices include real citation-ID prefixes; full identifiers, exact excerpts, source titles and source identity remain inspectable. Duplicate brief source labels include their existing evidence IDs. Reading width is bounded without redesigning the brief.
3. **Review versus brief Save.** Forms explain what **Save information review** records and why a brief requires its separate **Save**. Missing evidence/firsthand basis is caught before validation/resolution submission. Refusal keeps typed reasoning; Cancel requires deliberate discard of a dirty review. Completion/feedback controls stay grouped. Existing account-qualified working-brief return and saved/pending state are rendered from the existing session on reload. No autosave or new persistence is introduced.

Human validation is not independent corroboration.
